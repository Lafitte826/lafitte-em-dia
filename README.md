# Lafitte em Dia

App das rotinas do Condomínio Maison Lafitte (zelador, limpeza e portaria): leituras de água, gás e energia, verificações, rega, limpeza e salão de festas. Os dados ficam no próprio celular e o resultado vai por WhatsApp para o síndico.

Para atualizar as leituras anteriores, edite `dados.js`. A cada mudança, troque `CONFIG.versao` para o celular pegar a versão nova.

`CONFIG.teste: true` mostra a barra para simular o dia (versão de teste para o conselho).
